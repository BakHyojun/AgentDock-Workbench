# AgentDock Workbench 1.1.8100 — Windows x64

업스트림 Workbench v1.1.8을 기준으로 한 fork 배포입니다. 한국어 표시와 고정된 ripgrep 번들을 유지하고, CUA 데스크톱 제어 플러그인을 기본으로 포함합니다. 이 fork는 이제 Setup으로만 업데이트합니다.

## 변경 사항 (1.1.17100 대비)

### 업스트림 1.1.8 반영

- 중간 삽입: 새 추가 메시지를 받으면 에이전트가 단계 요약을 보여 주고 같은 턴에서 작업을 이어 갑니다.
- 활동 판정: "최근 활동"은 실제 상호작용 뒤 120초로만 판단하고, 실행 중인 호출은 별도로 표시합니다.
- 대화 목록 응답의 식별자를 검증하고, 잘못된 응답은 마지막 정상 목록을 유지한 채 격리합니다.
- 권한: "사용자 지정 권한 설정 사용" 스위치를 추가했습니다. 끄면 실행 모드가 권한을 결정하고, 저장된 설정은 보존됩니다.
- 설치: 현재 버전과 롤백용 버전 하나를 남기고 이전 버전을 정리합니다. 터널 프로세스 정지 경합을 처리합니다.
- 보안: Skill·작업 상태 파일의 경로 경계, 플러그인 Git·압축 원본 검증, 브라우저 입력 전달을 강화했습니다.
- 에이전트 도구가 종료 상태를 보존하고, 실패 시 복구 방법을 안내합니다.
- 소스에는 Android, macOS, Linux CLI도 포함되지만 이 배포물은 Windows x64만 제공합니다.

### fork 변경

- **CUA 데스크톱 제어 플러그인**: Setup이 설치를 마친 뒤 `%USERPROFILE%\.agentdock\plugins\cua-driver`에 넣습니다. 에이전트(예: ChatGPT)가 로컬 [cua-driver](https://github.com/trycua/cua)로 이 PC의 화면을 보고 앱을 조작할 수 있습니다. cua-driver는 [공식 절차](https://cua.ai/docs/cua-driver)로 따로 설치해야 합니다.
  - 사용자가 끄거나 삭제한 플러그인, 같은 이름으로 직접 설치한 플러그인은 Setup이 건드리지 않습니다.
  - 수동 설치와 사용 방법은 설치된 플러그인 폴더의 `README.md`에 있습니다.
- **외부 MCP 도구**
  - 스크린샷 같은 이진 결과를 한 번만 전송합니다.
  - 승인할 때 "이 작업공간에서 허용"은 그 도구 하나(예: `cua-driver:click`)만 허용합니다. 이전에는 모든 외부 MCP 서버를 허용했습니다.
- **Setup 전용 업데이트**: 트레이와 창의 업데이트 항목은 이 Releases 페이지를 안내합니다. `agentdock update`는 온라인 확인과 다운로드를 거부합니다.
- **설치 수정**
  - 관리자 모드 AgentDock이 쓴 파일(소유자 `Administrators`) 때문에 일반 권한 Setup이 롤백 준비 단계에서 실패하던 문제를 고쳤습니다.
  - 1.1.8의 새 추출 경로에서 ripgrep이 빠지던 두 곳을 보완했습니다. x64 Setup은 ripgrep이 없는 payload를 거부합니다.
- **한국어**: 1.1.8에서 새로 생긴 화면 문구를 번역했고, 차이 미리보기 잘림 안내의 줄바꿈을 고쳤습니다.

## 버전과 업그레이드

버전 규칙은 `1.1.<업스트림 패치>100`입니다. 1.1.8100은 숫자상 1.1.17100보다 작지만, Setup은 버전 순서를 검사하지 않으므로 기존 설치 위에 그대로 업그레이드됩니다. 1.1.17100의 앱 안 업데이트 확인에는 이 버전이 나타나지 않으니, `AgentDockSetup-amd64.exe`를 직접 실행하세요. 기존 설정, 보호된 자격 증명, 사용자 데이터는 유지됩니다.

## 배포물

- `AgentDockSetup-amd64.exe`: 오프라인 설치파일
- `build-report.json`: 소스 커밋과 빌드 정보
- `verification-scope.json`: 실제로 수행한 검증 범위
- 각 파일의 `.sha256`

Setup 전용 업데이트 방침에 따라 ZIP payload와 `install.ps1`은 게시하지 않습니다. 제품 파일은 **Authenticode 서명이 없는 unsigned 빌드**입니다. 동봉한 cloudflared는 공식 서명을 검증합니다.

## 검증 범위

GitHub Actions 없이 로컬 Windows x64 환경의 깨끗한 clone에서 빌드했습니다.

- 로컬 회귀: gofmt·`go vet ./...` 통과. Go 시험 60개 패키지 통과, 실패 1건은 부하에 따라 결과가 바뀌는 `internal/taskstate` 2초 성능 목표 시험입니다(main에서도 같음). 실제 ripgrep 통합 4개 패키지, 제어판·시험 프로젝트 빌드, 순수 정책 920, 한국어 표시 6,876, native 계약 171 assertions, Setup 스크립트(PowerShell 5.1·7)와 설치기 정적 계약이 통과했습니다.
- 배포물 검증기가 버전, 소스 커밋, ripgrep 5개 파일, Core Skill 3개 bootstrap, CUA 플러그인 공급, checksum을 확인했습니다.
- 독립 에이전트 3개가 1.1.8 병합을 적대적으로 검토했고, 확인된 결함은 모두 수정했습니다.
- 실제 설치(운영 PC, 사용자 수행): 첫 1.1.8100 후보(`db201dc`)가 기존 1.1.17100 위에 설치됐습니다. 같은 코드의 최종 후보(`b3a7290`, 문서만 다름)는 그 관리자 모드 설치 위에 설치됐고, 플러그인 자동 설치도 확인했습니다.
- 수행하지 않은 것: 이 배포 파일 자체의 설치·업그레이드·롤백 시험, Linux와 race 시험, WPF 화면 시험, native 복구 시험, ChatGPT에서 화면 이미지가 모델에 보이는지 확인. 코드 서명도 하지 않았습니다.
