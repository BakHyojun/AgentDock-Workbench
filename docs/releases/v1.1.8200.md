# AgentDock Workbench 1.1.8200 — Windows x64 (Pre-release)

한국어 표시 누락과 Activity 이력 저장을 보완한 fork 배포입니다. 실제 설치·업그레이드 수용 시험 전의 **공개 사전 릴리즈**입니다.

**[Windows 설치파일 다운로드](https://github.com/eerraa/AgentDock-Workbench/releases/download/v1.1.8200/AgentDockSetup-amd64.exe)**

## 변경 사항 (1.1.8100 대비)

- 실행 센터의 미귀속 그룹·독립 호출·이전 작업공간 제목, 권한 변경과 대화/작업 관리 기록, 일괄 작업 결과, 승인창의 제품 안내문을 한국어로 표시합니다. 이전 관리 기록은 조회 시 보완하므로 이력 초기화가 필요하지 않습니다. 사용자 제목·경로·외부 도구 결과와 원본 기술 진단은 보존합니다.
- 일반 모드에서는 256 KiB를 넘는 대형 Activity 출력의 전체 이력 대신 최대 2 KiB 프리뷰를 보존합니다. 실제 도구 결과 전달은 유지합니다. 전체 캡처가 필요한 경우 디버그 모드를 사용할 수 있습니다.
- 실행/응답/명령/승인 대기가 없는 상태에서 실행 기록을 초기화할 수 있습니다. 대화·작업·설정 초기화와는 별개이며, 최근 payload 보호와 부분 정리 실패를 표시합니다.
- 기존 설정 보존 설치에서 Installer trial 동안 stable GUI shim이 Core task 시작을 거부하던 경로를 수정했습니다. 정확한 runtime root·trial identity·lock 검사는 유지합니다. 실제 Setup 설치 성공을 검증한 것으로 표현하지 않습니다.
- rg 15.2.0, CUA 데스크톱 플러그인, Setup 전용 업데이트 정책을 유지합니다. 앱의 업데이트 항목은 fork Releases 페이지를 엽니다. GitHub Actions 빌드는 차단된 상태입니다.

## 배포물과 검증

Windows x64 설치에는 Assets의 **AgentDockSetup-amd64.exe**를 사용하세요. GitHub가 자동 제공하는 Source code ZIP/TAR는 설치파일이 아닙니다. 설치파일·빌드 정보·검증 범위와 각 SHA-256, 총 6개 자산을 제공합니다. 온라인 updater용 ZIP과 install.ps1은 배포하지 않습니다.

- 버전: `1.1.8200` (사용자 지정). upstream 기준선은 Workbench 1.1.8 `4bd778d4077bbe58cfe19e4abb777f660694377b`입니다.
- 깨끗한 일반 clone의 빌드 source와 태그 대상: `0383a90d252ec8e924a166254c7db1e09437bf90`.
- Setup: 112,690,821 bytes. SHA-256: `4f8224875f68d858dd719c95657a0122c313ccf59f32d03ba13708bd3ce3621d`.
- 한국어/모델 7,310 assertions, 데스크톱 정책 923 assertions, Go vet·format·version 검사 통과. 실제 Setup 내 한국어 리소스 1,171개, 보완 29키, desktop assembly, rg 5파일, CUA 4파일과 패키지 source identity·checksum을 확인했습니다.
- 전체 Go suite의 기존 실패 2건은 남아 있습니다: `TestManagedTaskFirstPage1000`의 2초 성능 목표, `TestSearchTextRGExitCodes`의 오류 분류 기대값. 관련 Activity/app/HTTP 및 installer/shim 시험은 통과했습니다.
- **미실행:** 실제 isolated Windows 설치·기존 설정 보존 업그레이드·롤백, WPF 화면 수용, Linux/race 시험. 운영 PC의 Setup/Core는 실행하거나 변경하지 않았습니다.
- **미서명:** AgentDock/Setup은 Authenticode unsigned입니다. 번들 cloudflared의 공식 서명은 Valid입니다.

동봉한 build-report.json의 `candidate-not-released`와 verification-scope.json의 게시 `not_run`은 빌드 시점의 검사 스냅샷입니다. 원본 metadata를 보존한 채 같은 후보 bytes를 공개 사전 릴리즈로 등록합니다. GitHub 게시·재다운로드 결과는 저장소의 [한국어 보완 핸드오버](https://github.com/eerraa/AgentDock-Workbench/blob/main/docs/eerraa/korean-presentation-completion.ko.md)에 별도로 기록합니다.
